Record

  • State before: the two VMs stopped in the middle of the row. Three 1 halt statements were in the code and in the tests, and a Halt with no handler ends a headless image. Of the 80 tests that ran, 62 passed.
  • The package is a research prototype of an escape analysis for Pharo methods. An object escapes a method when a reference to it can stay after the activation ends.
  • Repairs here (fixes/fouziray-escapeanalysispharo.st, 33 entries; the manifest row also loads tomooda/HoneyGinger, which 4 tests use and no baseline names):
    • The three 1 halt statements are gone. The runner now also records a Halt as an error of the test.
    • Three tests use the AST API of an older Pharo (selector: with a String, loadProject:).
    • The analyzer (EscapeAnalyzerVisitor) answered "escapes" for objects that do not escape. The causes, each shown with a probe:
      • A variable in a block was an escape, also in a block that the compiler inlines (ifTrue:, timesRepeat:).
      • A recursive send made a new context down to the depth limit, and the limit marks the receiver as an escape.
      • A store into an instance variable was an escape at once, also when the object that gets the value does not escape.
      • The result of a message was taken for the receiver of the message.
      • The flag "the result is returned" stayed set after the last return of the root method.
      • A primitive that only reads its receiver (ProtoObject>>class) was an escape.
      • The name self of a callee was looked up in the context of the caller. That tied objects together that have no relation, and one test made 21779 contexts.
    • Two tests had wrong expected values (a method name copied from another test, and a count of contexts). One test passed before only because its list was empty; the code that it runs is repaired.
    • ObjectInlining>>assignObjectCreatedInlineToTmp: was a stub. It is written now, as small as its test needs.
  • Result: 82 tests, 81 pass and 1 skip on the two VMs, in a run from a new load.
  • Open: EscapeTest>>testComplexWeighterGraph. The author skips the test (self skip, with the flag #false): the analyzer says that two objects escape, and the test says that they do not. The test is right by the definition. A repair must analyse the body of a block at the place where the block is made. That change gives another answer for three tests of the same class (testTempInBlock, testReturnTempInBlock, testArgBlockReturnsTemp), which assert the careful answer. The author of the package must decide which answer is right. The test is not accepted: the row is not clean.

fix value: #ObjectInlining value: #assignObjectCreatedInlineToTmp:
	value: [ :source | (source includesSubstring: 'inlineTmp') not ]
	value:
'assignObjectCreatedInlineToTmp: aCompiledMethod
"Answers a method like aCompiledMethod in which each object that the method creates inside an expression (a send of #new to a global that is not the value of an assignment) is first assigned to a new temporary variable, so that the analysis tracks the object under a name. The new method has the selector of aCompiledMethod with the prefix inlinedTmp_ and is compiled in the class of aCompiledMethod."

| astClone counter newNodes selector |
astClone := aCompiledMethod ast copy.
counter := 0.
newNodes := astClone allChildren select: [ :each |
	            each isMessage and: [
		            each selector = #new and: [
			            each receiver isGlobalVariable and: [
				            each parent isAssignment not ] ] ] ].
newNodes do: [ :newNode |
	| statement sequence tmpName |
	counter := counter + 1.
	tmpName := ''inlineTmp'' , counter printString.
	statement := self findEnclosingStatementNodeFor: newNode.
	sequence := statement parent.
	sequence addTemporaryNamed: tmpName.
	sequence
		addNode: (ASTAssignmentNode
				 variable: (ASTVariableNode named: tmpName)
				 value: newNode copy)
		before: statement.
	newNode replaceWith: (ASTVariableNode named: tmpName) ].
astClone selector: #inlinedTmp_ , astClone selector.
selector := aCompiledMethod methodClass
	            compile: astClone newSource
	            classified: #inlining.
^ aCompiledMethod methodClass >> selector'.
