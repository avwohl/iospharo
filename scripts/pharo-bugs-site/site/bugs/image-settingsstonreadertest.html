The test loads a settings STON file whose ClassStoredSetting names an instance variable that no longer exists. STONReader signals InstanceVariableNotFound, and SettingsStonReader>>load did not handle it, so the test errored (marked expectedFailure). The image code defect: load now answers an empty collection and stores nothing when a stored setting names a missing instance variable (the stream is still closed by the ensure:). The test also had a vacuous final assertion (it checked a fresh reader, not the one that did the load); it now checks the reader that loaded, and asserts that load raises no Error. The expectedFailure pragma is removed.

Fix

How to apply an entries file: file in 00-header.st and the entries file as one chunk (the iospharo script scripts/gen-image-fixes.py makes that chunk). Each entry checks for the defect first and prints FIXED, ADDED or SKIP. Download 00-header.st.

20-SettingsStonReaderTest.st (download)
fix value: #SettingsStonReader value: #load
	value: [ :source | (source includesSubstring: 'InstanceVariableNotFound') not ]
	value:
'load
	"It loads all instances of StoredSetting from a stream.
	 A stored setting that names an instance variable which no longer exists
	 (the setting class changed since the file was written) cannot be loaded:
	 nothing is stored and an empty collection is answered."
	stream ifNil: [ ^ #() ].
	stream atEnd ifTrue: [ ^ #() ].
	[ | reader |
		reader := STON reader on: stream; yourself.
		[ storedSettings := reader next ]
			on: InstanceVariableNotFound
			do: [ :ex | storedSettings := nil ]
	] ensure: [ stream close ].
	^ storedSettings ifNil: [ #() ]'.

fix value: #SettingsStonReaderTest value: #testNonExistingStoredSettingVariable
	value: [ :source | (source includesSubstring: 'expectedFailure') or: [ source includesSubstring: 'SettingsStonReader new storedSettings' ] ]
	value:
'testNonExistingStoredSettingVariable
	reader stream: MockSettings changedClassStoredSettingVariable readStream.
	self shouldnt: [ reader load ] raise: Error.
	self assert: reader storedSettings isNil'.
