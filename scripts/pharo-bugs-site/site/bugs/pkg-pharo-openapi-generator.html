Record

  • State before: LOAD-FAIL (KeyNotFound: key 'BaselineOfOpenAPI').
  • Causes, all in the repository, which is an unfinished state:
    • The repository has no .project file and no src/.properties, so Iceberg finds no package in src.
    • The classes OAContact, OAInfo, OAComponents and OAOperation, which the code and the tests use, are not in the repository.
    • One test has a literal #{...} that Pharo 14 does not read, and one test uses a mock that does not pass visit: on.
    • The baseline pins a version of Mocketry of 2019.
  • Repair here: patches/alkalinan-pharo-openapi-generator.patch adds the two project files and the four classes (as small as the tests need), nests the JSON mapping of the info object, corrects the two tests and names the present Mocketry.
  • Limit: the four classes are ours. The author must add the real ones.
  • Result: 16 of 16 pass on the two VMs.
