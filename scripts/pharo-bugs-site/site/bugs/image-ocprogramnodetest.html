The test selects the interval ' := 1' in 'a := 1111111111111111.'. The interval does not touch the variable, so OCProgramNode>>bestNodeFor: found one intersecting child (the literal) and answered the literal. The test expected the assignment. The defect is in image code, not in either VM. The fix adds OCAssignmentNode>>bestNodeFor:. It calls super, and when the answer is the assignment's value and the interval starts after the assignment start but before the value start, it answers the assignment. The expectedFailure pragma is removed from the test; the assertions are unchanged. A first attempt that changed OCProgramNode>>bestNodeFor: for all node types broke testBestNodeFirstTempsAndFirstCommentGivesVariableNode, so I narrowed the fix to the assignment node.

Fix

How to apply an entries file: file in 00-header.st and the entries file as one chunk (the iospharo script scripts/gen-image-fixes.py makes that chunk). Each entry checks for the defect first and prints FIXED, ADDED or SKIP. Download 00-header.st.

20-OCProgramNodeTest.st (download)
"OCAssignmentNode>>bestNodeFor: answered the value (the right side) when the interval starts in the ' := ' between the variable and the value, because the value is the only child the interval touches.  The interval lies in the assignment, so the assignment is the best node."
add value: #OCAssignmentNode value: #bestNodeFor: value: 'querying' value:
'bestNodeFor: anInterval

	| node |
	node := super bestNodeFor: anInterval.
	^ (node == value and: [ anInterval first >= self start and: [ anInterval first < value start ] ])
		ifTrue: [ self ]
		ifFalse: [ node ]'.

fix value: #OCProgramNodeTest value: #testBestNodeForReturnAStatementWhenIntervalInStatementWithoutLeftPart
	value: [ :source | source includesSubstring: '<expectedFailure>' ]
	value:
'testBestNodeForReturnAStatementWhenIntervalInStatementWithoutLeftPart
	"When the selection is not close to the variable but to the colon, the assignment is returned, not the literal (the right value)"
	| ast start body |
	body := 
''m
| a |
a := 1111111111111111.
''.

| a |
'' size.
		
	ast := (OCParser parseMethod: body) bestNodeFor: (start + 2 to: start + 6).
