The test called self skip because a remembered window extent could break it. SpPresenter class>>preferredExtent:/customExtent stores a resized window's extent per class, and a sibling test in the class run left 240@77 behind, so the unskipped test got 240@77 instead of 550@850 on both VMs. Run alone, the unskipped test already passed. The fix removes the skip, resets the remembered extent at the start (the author's own commented-out resetRememberedResizeExtent line), and restores the previous remembered extent and showInspector in the ensure block. The assertion is unchanged (initialExtent equals 550@850) and the window close is nil-safe.

Fix

How to apply an entries file: file in 00-header.st and the entries file as one chunk (the iospharo script scripts/gen-image-fixes.py makes that chunk). Each entry checks for the defect first and prints FIXED, ADDED or SKIP. Download 00-header.st.

20-StObjectTranscriptPresenterTest.st (download)
fix value: #StObjectTranscriptPresenterTest value: #testTrueShowInspectorShowsInspector value: [:s | s includesSubstring: 'self skip'] value: 'testTrueShowInspectorShowsInspector
	"The window extent is remembered per class when a window is resized (SpPresenter class>>preferredExtent:). Other tests open windows and can leave a remembered extent behind, so this test starts from the default extent and puts the remembered extent back afterwards."
	| st win current remembered |
	current := StObjectTranscriptPresenter showInspector.
	remembered := StObjectTranscriptPresenter instVarNamed: #customExtent.
	[
	StObjectTranscriptPresenter resetRememberedResizeExtent.
	StObjectTranscriptPresenter showInspector: true.
	st := StObjectTranscriptPresenter new.
	st logger: StObjectTranscriptLogger instance.
	win := st asWindow.
	win resizable: false.
	win open.
	self assert: win initialExtent equals: 550 @ 850 ] ensure: [
		win ifNotNil: [ win close ].
		StObjectTranscriptPresenter showInspector: current.
		StObjectTranscriptPresenter instVarNamed: #customExtent put: remembered ]'.
