Record

  • State: 96 tests, 23 pass, 70 errors (NameLookupFailure: cannot resolve 'postgres'), 3 timeouts on the two VMs.
  • Cause: 73 tests need a PostgreSQL server. P3ClientTest class>>url answers psql://postgres:postgres@postgres:5432/postgres. The host postgres is the name of the service container of the CI of the repository, so the tests stop at the name lookup on this machine. No environment variable changes the URL.
  • No stand-in: the tests send real SQL and check what the server does (tables and types, the catalogs, notices, a statement timeout, time zones). A stand-in with replies that we write would only check the decoder of P3 against our own text.
  • The 3 timeouts: P3Client>>withConnection: tries a network error again 10 times and waits 5 s each time. A name lookup failure is a network error, so a test of the connection pool waits for 50 s.
  • One package defect, repaired in fixes/svenvc-p3.st: P3Client>>retryDelay: did not store its argument.
  • Open, for the owner: the row needs a PostgreSQL server (version 9.4 or later) on 127.0.0.1:5432 with the database postgres, the user postgres and the password postgres, and the tests need the host 127.0.0.1 in their URL. We install nothing without the word of the owner. The row is not clean.

Fix

Fixes file (filed in after the load): svenvc-p3.st (download)
"svenvc/P3: P3Client>>retryDelay: ignored its argument.  The method stored the
constant 5 (settings at: #retryDelay put: 5), so a caller that sets another
delay still waits 5 seconds between reconnection tries.  P3ClientTest>>testTimeout
calls retryDelay: 0 to have no wait, and a pool query on an unreachable host
(P3ConnectionPoolTest, 10 tries of 5 seconds) cannot be shortened either.  The
repair stores the argument."

fix value: #P3Client value: #retryDelay:
	value: [ :source | source includesSubstring: 'put: 5' ]
	value:
'retryDelay: seconds
	"Set the delay after which a reconnection will be tried on a failed connection, the default being 5 seconds.
	See also #retryCount:"

	settings at: #retryDelay put: seconds'.
