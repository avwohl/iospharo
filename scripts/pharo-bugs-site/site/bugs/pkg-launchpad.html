Record

  • The package loads Buoy. See the Buoy section (locks/ba-st-launchpad.txt).
  • State with the load repair only: 123 tests, 48 pass, 1 fail, 74 errors on the two VMs.
  • Cause of 71 tests: Launchpad calls CommandLineArguments>>copySubcommand, CommandLineArguments>>optionAt:ifPresent:ifAbsent: and CommandLineHandler class>>prepareSubcommand:. Pharo 13 had the three methods. Pharo 14 has a new design of the command line handler and does not have them. The repository has its own copies of the methods for GemStone.
  • Cause of 2 tests: BaselineOfLaunchpad has branches for pharo10.x to pharo13.x only, so the package Launchpad-Tracing-Fuel does not load on Pharo 14, and its test class does.
  • Repair: patches/ba-st-launchpad.patch adds a package Launchpad-Pharo14-Compatibility with the three methods and a pharo14.x branch in the baseline.
  • Cause of 1 test: three helper methods of Buoy (OSPlatform>>environmentAt:put: and two more) call the deprecated OSPlatform>>environment. fixes/ba-st-launchpad.st makes them use OSEnvironment current. The same change belongs in Buoy.
  • Result: 123 of 123 pass on the two VMs.

Fix

Fixes file (filed in after the load): ba-st-launchpad.st (download)
"Launchpad (ba-st/Launchpad, release-candidate), test helper of Buoy:
Buoy-Metaprogramming-Pharo-Extensions defines OSPlatform>>environmentAt:put:,
environmentAt:ifPresent:ifAbsent: and removeEnvironmentKey: with 'self
environment'.  OSPlatform>>environment is deprecated in Pharo 14 (the method is
in Deprecated14) and its message says 'Use OSEnvironment current instead'.
LaunchpadRootCommandTest>>set:to:during: and ConfigurationFromEnvironmentProviderTest
call these three methods, so a Deprecation reaches the test (seen:
testHandlingStartGreeterApplicationWithMixedConfiguration).  The three methods
answer through OSEnvironment current, which is what 'environment' answers.
The same change belongs in Buoy (see docs/upstream/package-repairs.md)."

fix value: #OSPlatform value: #environmentAt:ifPresent:ifAbsent:
	value: [ :source | source includesSubstring: 'self environment' ]
	value:
'environmentAt: aVariableName ifPresent: aBlock ifAbsent: anAbsentBlock

	^ OSEnvironment current
		  at: aVariableName
		  ifPresent: aBlock
		  ifAbsent: anAbsentBlock'.

fix value: #OSPlatform value: #environmentAt:put:
	value: [ :source | source includesSubstring: 'self environment' ]
	value:
'environmentAt: variableName put: value

	OSEnvironment current at: variableName put: value'.

fix value: #OSPlatform value: #removeEnvironmentKey:
	value: [ :source | source includesSubstring: 'self environment' ]
	value:
'removeEnvironmentKey: variableName

	OSEnvironment current removeKey: variableName'.
