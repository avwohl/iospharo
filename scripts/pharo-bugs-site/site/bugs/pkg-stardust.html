Record

  • State before: 71 tests, 48 pass, 23 errors on the two VMs (InstanceCreationFailed: The amount of model creators (3) should match the amount of arguments (4)).
  • Cause: GenericModelCreator class>>assertSizeOf:equalsArgumentCountOf: sends argumentCount to a Symbol. Stardust relied on the extension Symbol>>argumentCount of Buoy, which answers numArgs. That extension replaces a method of Pharo 14, and our Buoy patch removes it so that Buoy loads. The method of Pharo 14 answers numArgs + 1 (a Symbol in the place of a block).
  • Repair here: patches/ba-st-stardust.patch uses numArgs in the two places.
  • Result: 71 of 71 pass on the two VMs.

Test

Load the package into a Pharo 14 image (build 791) with the load expression of the test run, file in the fixes file of the row if there is one, and run the test classes of the package.
