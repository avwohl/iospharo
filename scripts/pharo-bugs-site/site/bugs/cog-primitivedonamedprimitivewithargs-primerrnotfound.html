Record

  • Defect: for a named primitive that does not exist, the real call fails with PrimErrNotFound, and the simulated call (primitive 218, used by Context>>tryNamedPrimitiveIn:for:withArgs:) fails with the generic code -1. The debugger simulation then gives another error code than the real execution. The image has CodeSimulationTest>>testErrorCodeNotFound set to skip.
  • Change: primitive 218 fails with PrimErrNotFound when the function does not exist.
  • Test (2026-11-17, a Debug build with the change): CodeSimulationTest gives 9 passes of 9 with the skip removed. The stock VM fails testErrorCodeNotFound ("Got #'not found' instead of nil").
  • Our VM gave nil for the real call and for the simulated call. This repository has the fix for that defect.

Test

"Run in a Playground of a Pharo 14 image."
| r |
r := CodeSimulationTest new veryBasicAt: 1.

	doPrimitive: 117 method: CodeSimulationTest >> #veryBasicAt: receiver: CodeSimulationTest new args: #(999) }
"Stock Cog: {#'not found'. {token. nil}}: the simulation loses the error code.  With the change the two agree."

Names such as scripts/vmrun.sh and scripts/cogdiff/ are scripts of the iospharo repository, which runs one VM at a time. cog is stock Cog, cogp is Cog with the change, ours is iospharo.

Fix

A change of the Cog sources (pharo-project/pharo-vm, branch pharo-12), on the local branch fix/named-primitive-not-found-in-simulation. State: committed on the branch, tested. Not sent upstream.

Subject: [PATCH] primitiveDoNamedPrimitiveWithArgs: PrimErrNotFound when the
 function does not exist

primitiveExternalCall fails with PrimErrNotFound when a named primitive
does not exist, so <primitive: 'name' module: 'm' error: code> gets
#'not found' in code.  primitiveDoNamedPrimitiveWithArgs, which the image
uses to simulate the same call (Context>>tryNamedPrimitiveIn:for:withArgs:),
failed with the generic code -1 for the same case, and the simulation
answered nil as the error code.

CodeSimulationTest>>testErrorCodeNotFound compares the two answers.  The
image has the test set to skip.  With this change the test passes with the
skip removed.

Measured on macOS 27, arm64, a Debug build:
  real call, before and after:  #'not found'
  simulated call, before:       nil
  simulated call, after:        #'not found'
