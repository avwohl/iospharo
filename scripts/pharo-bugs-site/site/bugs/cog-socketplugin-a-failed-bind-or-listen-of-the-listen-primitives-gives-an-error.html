Record

  • Defect: sqSocketListenOnPortBacklogSizeInterface does not test the result of bind and of listen. Socket>>setPort: of a UDP socket uses that function. On a port that another socket has, the image gets no error, the socket stays unbound, and it receives nothing on that port.
  • Measurement (scripts/cogdiff/socket_bind_in_use.st, 2026-11-17): the stock VM answers "no error" for the second setPort: of one UDP port, and the second socket does not have the port. Our VM signals SocketError: Address already in use. For TCP the image uses primitiveSocketBindToPort, which tests the result, so the two VMs agree there.
  • Found by: the package NetworkExtras of bouraqadi/PharoMisc. Its tests make two multicast sockets on one port and passed on the stock VM only because the second bind failed with no error.
  • Change: the function records the socket error and fails the primitive, as sqSocketBindToPort does.
  • Test: with the change, the script gives SocketError: Address already in use for UDP on the patched Cog.
  • Not tested: Windows and Linux.

Test

A probe that prints the same lines on a correct VM. Run it with Pharo.image eval or file it in:

socket_bind_in_use.st (download)
"socket_bind_in_use.st -- a second socket takes a port that a first socket
 has, for UDP (setPort:) and for TCP (listenOn:backlogSize:).

   scripts/vmrun.sh eval cog  scripts/cogdiff/socket_bind_in_use.st
   scripts/vmrun.sh eval cogp scripts/cogdiff/socket_bind_in_use.st
   scripts/vmrun.sh eval ours scripts/cogdiff/socket_bind_in_use.st

 The system refuses the second bind (Address already in use).  The answer
 shows if the image gets that error, and which port the second socket has.

 Measured 2026-11-17 (Pharo 14 build 791):
   stock Cog   UDP: no error, and the second socket does not have the port.
               TCP: SocketError: Address already in use.
   our VM      UDP and TCP: SocketError: Address already in use.
 The stock VM does not test the result of bind in
 sqSocketListenOnPortBacklogSizeInterface, which Socket>>setPort: uses."

Fix

A change of the Cog sources (pharo-project/pharo-vm, branch pharo-12), on the local branch fix/socket-listen-bind-result. State: committed on the branch, tested. Not sent upstream.

cog-socket-listen-bind-result.patch (download)
From 6361258724d1bc67541399678594d66a8338d592 Mon Sep 17 00:00:00 2001
From: Aaron Wohl
Date: Tue, 17 Nov 2026 11:23:42 -0500
Subject: [PATCH] SocketPlugin: report a failed bind or listen of the listen
 primitives to the image

sqSocketListenOnPortBacklogSizeInterface did not test the result of bind
and of listen.  Socket>>setPort: of a UDP socket on a port that another
socket has then gave no error, the socket stayed unbound, and it received
nothing on that port.

The function now records the socket error and fails the primitive, as
sqSocketBindToPort does.  The image then signals SocketError with the text
of the system (Address already in use).
