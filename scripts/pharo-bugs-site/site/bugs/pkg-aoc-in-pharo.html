Record

  • State before: 20 tests, 7 pass, 13 errors on the two VMs (OSEnvironment, Dictionary and Array do not understand #atGrid:; SmallInteger does not understand #y).
  • Causes, in the package:
    • The last commit of the repository (20b89cf) renamed at: to atGrid: also in code whose receiver is not a GridArray. Only GridArray has atGrid:.
    • GridArray>>x:y: and x:y:put: gave an Integer to atGrid:, which takes a Point.
  • Repair (fixes/shnarazk-aoc-in-pharo.st): the 10 methods send at: again, and the two GridArray methods use at: and at:put:.
  • 6 tests cannot apply on this machine (Y2025Day05Test, Y2025Day08Test). They read puzzle input files from a directory data under the home directory. The repository has no such file, and Advent of Code asks that the puzzle text and the inputs are not copied. The setUp of the two classes skips the test with that reason when the file is absent. not-applicable/shnarazk-aoc-in-pharo.txt has the proof.
  • For the owner of the package: the solution of day 8 of 2025 is not complete (part2 answers 0), so testPart2 cannot pass with the input file either.
  • Result: 14 pass and 6 skips on the two VMs; each skip is in the not-applicable file.
