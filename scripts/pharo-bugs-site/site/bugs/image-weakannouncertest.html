  • Methods: AnnouncementSubscription>>makeWeak, WeakAnnouncerTest>>testNoWeakBlock

testNoWeakBlock was an expected failure. AnnouncementSubscription>>makeWeak raised 'Not currently available due to missing ephemerons support' for block actions. The test comment states the intended behaviour: there is no weak block, a block subscription never goes away. The fix makes makeWeak return self (stay strong) when the action is a block, and removes the <expectedFailure> pragma from the test. The test body is unchanged. The same defect is in image code, not in either VM. No other code or test in pharo/src depends on the old error.

Fix

How to apply an entries file: file in 00-header.st and the entries file as one chunk (the iospharo script scripts/gen-image-fixes.py makes that chunk). Each entry checks for the defect first and prints FIXED, ADDED or SKIP. Download 00-header.st.

20-WeakAnnouncerTest.st (download)
"A block action holds its receiver strongly and there are no ephemerons, so a
 block subscription cannot be weak.  makeWeak keeps the subscription strong
 instead of raising an error, as testNoWeakBlock states."
fix value: #AnnouncementSubscription value: #makeWeak
	value: [ :s | s includesSubstring: 'missing ephemerons support' ]
	value: 'makeWeak

	"A block holds its receiver strongly and there are no ephemerons, so there is no weak block subscription: stay strong."
	action isBlock ifTrue: [ ^ self ].

	^ announcer replace: self with:
		(WeakAnnouncementSubscription new
			announcer: announcer;
			action: action asWeakMessageSend;
			subscriber: subscriber;
			announcementClass: announcementClass)'.
fix value: #WeakAnnouncerTest value: #testNoWeakBlock
	value: [ :s | s includesSubstring: '<expectedFailure>' ]
	value: 'testNoWeakBlock
	"There is no such thing as a weak block, these things never go away."

	| counter |

	self longTestCase.

	counter := 0.

	(announcer when: AnnouncementMockA do: [ :ann | counter := counter + 1 ] for: self) makeWeak.

	Smalltalk garbageCollect.
	announcer announce: AnnouncementMockA.
	self assert: counter equals: 1.

	Smalltalk garbageCollect.
	announcer announce: AnnouncementMockA.
	self assert: counter equals: 2'.
