Record

  • Defect: BaselineOfPharoAdventOfCode names a package AdventOfCode. The repository has no package with that name, and its history never had one.
  • Effect: the load stops with KeyNotFound: key 'AdventOfCode'.
  • Repair: patches/terryc321-pharo-advent-of-code.patch names four packages of the repository: Advent-Of-Code-2015 (needs PetitParser2), Advent-Of-Code-2016, Advent-Of-Code-2020 and AdventCode2025.
  • Not in the patch, for the owner of the package to decide: Advent-Of-Code-2018 needs Bloc. AdventCode and AdventCode2015 have the same class names as Advent-Of-Code-2015 (60 and 19 class files), so the three packages cannot be in one image.
  • State with the patch only: 98 tests. Stock Cog: 72 pass, 7 fail, 18 errors, 1 timeout. Our VM: 73 pass, 7 fail, 18 errors.
  • Result with fixes/terryc321-pharo-advent-of-code.st: 96 of 96 pass on the two VMs. The causes of the 26 tests, each from the sources:
    • String>>asSymbolOrInteger is in the package AdventCode, which cannot load with Advent-Of-Code-2015 (11 tests of AOC2015Day7Test). The fixes file adds the method as an extension of Advent-Of-Code-2015.
    • AOC2015Day13>>parse: and AOC2015Day15>>split: split a text at Character lf. The text is a string literal of a method, and the load gives the literal CR line ends (5 tests). The two methods now use String>>lines.
    • AOC2015Day8>>repoDir is a directory in the home directory of the author. The input file is in the repository. The method now asks the Iceberg repository for its directory.
    • AOC2025Day6>>solution1Part2 and solution2Part2 used the result of puzzleInputParsed2 in a form that a later change of the author broke.
    • Tests that cannot pass as written: a test with the number of another day, a test that calls a selector that the class does not have, a test that asserts in a forked process and ends with true = false, and a test that fails on purpose (AOC2016Day1Test>>testFailing01). Each test now makes the check that its name and its comment describe.
    • AOC2015DayTestTemplate is a template to copy. Its two tests call notYetImplemented. The class is now abstract, so the test count is 96.
    • AOC2015Day25Test>>testPart1 makes 18 million steps of a Generator. The test took 7.5 s on our VM and more than the 10 s default time limit on stock Cog. The test class now has a time limit of 2 minutes.
