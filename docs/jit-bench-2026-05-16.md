## Key Wins

1. **IC probe default-on + J2J trampoline bypass** — biggest single win.
   Routes IC HIT through chain loop's ExitSendCached path (skipping the
   buggy J2J trampoline conversion that propagated callee return-values
   as caller's).  +25-35% sends throughput.

2. **Tagged-arith for + / -** — saves ~6 instructions per SmI arith.
   Applied to both bytecode emit (0x60/0x61) and prim prologue (1/2).
   The tagged form `(val << 3) | 1` pre-shifts by 8, so 64-bit JO on
   `add a_bits, b_bits` directly catches SmI-range overflow without
   needing separate untag and retag overflow checks.  Also fixes a
   latent retag-overflow bug in the prim prologue path.

3. **Skip untag in compare ops** — `x → 8x+1` is monotonic for signed
   values, so cmp on tagged bits matches cmp on untagged.  Saves 2×sar
   per `<`, `>`, `<=`, `>=`, `=`, `~=`.

4. **Defer send state setup** — `state.icDataPtr`/`sendArgCount`/`ip`
   are only needed for paths that return to the chain loop.  The
   inline-spec paths (getter/setter/returnsSelf) continue inline.
   Saves ~5 instructions per inline-spec HIT.

5. **Cmov with memory source** in comparisons / prim identity-eq —
   replaces "load trueOop into reg + cmov reg→rsi" with single
   "cmov [rdi+OFF_TRUEOOP] → rsi".  Saves 1 instruction per comparison.

6. **Inline emit of `*`, `bitAnd:`, `bitOr:`, `bitShift:`** —
   prevents methods using these from compiling as bail-on-entry stubs.

## Variance Note

Bench run-to-run variance is large on a shared machine — runs of the
same config can swing 10-30% on iterator-heavy benches (`collect`,
`sieve`).  `tinyBenchmarks sends/sec` is the most stable metric.
On user CPU time (via `/usr/bin/time -f "%U"`), the entire benchmark
suite typically runs 15-20s post-session vs 19-22s pre-session.

## What didn't work (reverted)

- 2-slot polymorphic IC probe — high variance, no clear win.
- `canJITActivate` stub-skip — stub-trip apparently faster than interp.
- Conditional jumps default-on — flaky on the differential fuzzer
  (varies 5/39 to 39/39 PASS between runs).  Off by default.
- `PHARO_ASMJIT_T1_FORCE_RESUME_FOR_SENDS=1` — deeper state desync
  un-rooted.
- IC probe `cmp rdx, 0` removal — within noise but slightly slower.
- Split object/imm IC probe paths — duplicated probe doubled code
  size, regressed CPU time.
- `movzx rcx, r8w` instead of `mov + and 0xFFFF` — slightly slower
  on the test machine.

## Knobs Available

- `PHARO_T1_NO_IC_PROBE=1` — revert to probe-off behavior
- `PHARO_T1_NO_J2J_TRAMP=0` — re-enable the broken trampoline path
- `PHARO_ASMJIT_T1_ENABLE_JUMPS=1` — enable conditional-jump emit
  (known-flaky; sieve 3x faster but fuzzer variance)
